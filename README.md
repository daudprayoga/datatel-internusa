## 5 Pilar Layanan Unggulan

1. **Active Networking System Solution**
   - LAN / WAN, Enterprise Routing & Switching, Network Blueprint & 24/7 Diagnostics
2. **Data Center, Design & Build**
   - Kepatuhan Standar Internasional TIA-942, Raised Floor, PAC, UPS, FM-200 Fire Suppression, EMS
3. **Structured Cabling Systems Certified (SCS)**
   - Standar ANSI/TIA/EIA 568-B, BS EN 50173-1:2011 & IEC 60794, Cat 6A & Fiber Optic Backbone
4. **Digital CCTV Surveillance System**
   - Traditional & IP CCTV High Definition, ANPR, Industrial Plant & Safety Monitoring
5. **Access Control System**
   - Smart Card RFID, Biometric (Face/Fingerprint), Server Room Security, Integrasi Fire Alarm

## Tech Stack Frontend

- **Framework**: Next.js 16 (App Router)
- **Library**: React 19, TypeScript
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Database / ORM**: Prisma ORM, MySQL

## Menjalankan Aplikasi Secara Lokal

```bash
# Menjalankan development server
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.
